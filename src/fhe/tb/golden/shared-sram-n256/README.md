# Pre-reuse deterministic reference

Captured from RTL `69794109` and Aloha vendor `59c4efb`, N=256, two limbs,
default deterministic seeds and input generated by `tvgen/gen_roundtrip.py`.
These are public test keys, not provisioned secrets.

`key.hex`: limb-major resident key, N coefficients per limb, 54-bit hex words.
`ciphertext.hex`: limb-major coefficients, alternating c0[i] and c1[i], u64 words.
The SRAM reuse regression compares both limbs, so matching errors in hardware
encrypt/decrypt cannot hide a changed secret or ciphertext. Do not regenerate
these from the implementation under test.
